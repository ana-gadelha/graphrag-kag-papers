Pauta
Alinhamento do Projeto Final da disciplina Tendências em Ciência da Computação.

Decisões Tomadas
Foi definido que a equipe irá desenvolver inicialmente um MVP (Produto Mínimo Viável), visando garantir a entrega funcional do sistema dentro do prazo da disciplina.

O sistema deverá:

Armazenar papers científicos em um banco Neo4j;
Permitir busca vetorial por similaridade;
Realizar consultas utilizando relacionamentos do grafo;
Utilizar um LLM para geração de respostas;
Exibir as fontes utilizadas (provenance);
Possuir interface simples para demonstração.

Escopo Inicial
A coleta será limitada a aproximadamente 20 a 30 artigos relacionados a:

GraphRAG
Knowledge-Augmented Generation (KAG)
Hybrid Retrieval
Knowledge Graph RAG
Multi-hop Reasoning
